# Rate setting

A borrower has two ways to set the interest rate on a loan request.

## Fixed rate (default)

The borrower sets a rate they are willing to pay. The loan request lists at that rate. Lenders fund it at the stated rate or the request expires.

## Auction (opt-in)

The borrower opts in to having the rate set by an auction. The mechanism prices the loan over time and across multiple lenders without breaking token fungibility.

See [The auction](auction.md) for the full mechanics.

{% hint style="warning" %}
The price-based auction is **not in MVP**. At launch, only the fixed-rate path is available. See [MVP scope](../roadmap/mvp-scope.md).
{% endhint %}
