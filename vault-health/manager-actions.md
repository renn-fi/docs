# What a manager can do

The manager has **one action** available at any time, regardless of health factor:

## Pause new funding

The existing book is left to wind down through repayments and redemptions; the vault just doesn't grow.

## Opening a fresh vault

If the manager wants to run **fresh capital under the same rules**, they can open a new vault. Existing depositors can redeem and deposit into the new vault on their own.

{% hint style="info" %}
Manager actions are **public on-chain**. Depositors can decide how to respond — staying, redeeming, or migrating to a new vault — based on the manager's track record.
{% endhint %}

## Future: twin vault automation

A planned [twin vault](twin-vault.md) mechanism will automate this rotation in a future version.
